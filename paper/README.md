# TMLR paper release candidate

This directory contains the de-anonymized, TMLR-formatted V1 manuscript source
for the locked multiclass imbalance benchmark. `main.tex` is a local release
candidate; do not submit it to TMLR because it contains author information.

The manuscript contains only the frozen V1 benchmark evidence. The expanded V2
study is a separate follow-up and must not be used to amend these results.

## Compile locally

The source uses the TMLR style files (`tmlr.sty`, `tmlr.bst`, and supporting
files from the JMLR-maintained [`tmlr-style-file`](https://github.com/JmlrOrg/tmlr-style-file)
repository). The checked-in versions are restored to their original bytes.
From this directory, compile the de-anonymized local release candidate with:

```powershell
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The manuscript references generated figures under
`../results/analysis/figures/`. A clean checkout must first reproduce the
ignored full-run and analysis artifacts, or the source will show a clear
placeholder box in place of a missing figure. Generated PDFs and auxiliary
files are intentionally not tracked.

## Anonymous TMLR package

The anonymous review source and supplementary ZIP are generated by
`scripts/build_release_artifacts.py` after the source is committed on the
feature branch and `paper/main.pdf` has been compiled. The script writes an
anonymous `main.tex` under
`output/staging/tmlr-anonymous/paper/`, copies the original style
files unchanged, and stages the paper figures. Its style assets are pinned to
their reviewed bytes. The transformed source uses TMLR's double-blind review
header and removes the author block and acknowledgments. Run
`scripts/build_release_artifacts.py --stage-only`, compile the staged source
in that `paper` directory with the same four LaTeX commands above, then copy
its `main.pdf` to `output/submission/tmlr-anonymous-submission.pdf`. Run
`scripts/build_release_artifacts.py` again to create
`output/submission/tmlr-anonymous-supplement.zip`, which contains the same
anonymous PDF. Its manifest withholds the Git commit and checks file hashes;
the author name, email, and local origin URL are scanned against the package.
Gate G compares every package member to the current release inputs, including
the identical PDF copies. Do not put a public repository link in the anonymous
supplement.

TMLR requires an anonymized PDF and anonymized supplementary material. The
supplementary ZIP must be no larger than 100 MB. Author affiliations, funding,
conflicts, OpenReview profiles, and action-editor recommendations are entered
privately by the authors in OpenReview, rather than in the anonymous PDF; see
the [TMLR author guide](https://www.jmlr.org/tmlr/author-guide.html).

## Review checklist

The companion [`review-checklist.md`](review-checklist.md) records the V1 paper
completion checks, evidence boundary, and remaining venue-preparation items.
Before submission, complete the author-only OpenReview metadata and obtain an
independent human technical and claim review. The checklist records these
items separately from the anonymous PDF/package checks.

See [`../docs/reproducibility.md`](../docs/reproducibility.md) for the frozen
run hashes, the distinction between analysis replay and model rerun, and the
current immutable-source boundary. The local working draft is not yet a
DOI-backed release.
