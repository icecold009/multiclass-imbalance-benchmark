# Scientific protection checklist for the manuscript revision

This checklist records the claims and distinctions that the prose revision and both local paper variants must preserve. It is an editorial control for the frozen evidence, not a new analysis plan. The full-run records and analysis outputs remain unchanged.

## Numbers and dataset scope

- [x] The study covers 11 public multiclass tabular datasets: 9 numeric and 2 mixed; the classifiers are logistic regression, random forest, and XGBoost.
- [x] The numeric core has 9 conditions and the mixed core has 7. Balanced Random Forest is a separate RF-only comparator.
- [x] Stratified shuffled five-fold CV uses seeds 0, 1, and 2, for 15 seed-fold records per dataset-classifier-condition cell. Macro-F1 is the sole primary metric; multiclass G-mean, MCC, balanced accuracy, and per-class recall are secondary.
- [x] The full run enumerated 5,445 records: 1,005 unsupported combinations and 4,440 applicable attempts, of which 4,191 were valid and 249 failed in the sampler (5.61%). There were 278 complete dataset-classifier-condition cells.
- [x] Unsupported records break down into 405 numeric SMOTENC, 330 non-RF Balanced Random Forest, and 270 ordinary SMOTE/ADASYN/Borderline-SMOTE on mixed data. All 249 sampler failures were numeric ADASYN: 207 no-sample failures and 42 no-majority-neighbour failures.
- [x] Complete-cell counts remain numeric 75/84/75 and mixed 14/16/14 for logistic regression/random forest/XGBoost. A complete cell contains all 15 seed-fold records; these totals are not fold counts.

## Protected method and measurement rules

- [x] Imputation, encoding, scaling, resampling, and training-fold class weights are fitted inside each training fold. Test folds are transformed and predicted only; they are never resampled or used to fit preprocessing.
- [x] Mixed data uses SMOTENC for synthetic sampling. Ordinary SMOTE-family conditions are unsupported on mixed data; categorical-only data is outside this paper. Numeric and mixed SMOTEENN/SMOTETomek use SMOTE and SMOTENC internally, respectively.
- [x] Mixed hybrid cleaning receives ordinal-coded categories, so nearest-neighbour cleaning distances can impose an artificial order on category codes. This caveat limits interpretation of mixed hybrid results.
- [x] Balanced Random Forest is evaluated only with random forest. Sampler or dataset failures remain explicit and are not scored as model outcomes.
- [x] The fixed conditions and classifier settings were not tuned after the full-run scores. The protocol was frozen internally before the run but was not publicly or independently timestamp-preregistered.
- [x] The frozen inferential block is the dataset, not a fold or seed. Planned Friedman/Nemenyi comparisons require family-wide complete cells and at least 3 dataset blocks. The raw-baseline implementation instead used pair-specific complete cases; those Wilcoxon/Holm outputs are exploratory.
- [x] Win/tie/loss uses a 10^-12 tolerance; Wilcoxon preprocessing removes exact zeros. Bootstrap intervals use dataset blocks, 10,000 resamples and NumPy generator seed 0; they are unadjusted and distinct from Holm-adjusted tests.
- [x] Runtime starts immediately before the pre-fit RSS read and stops immediately after prediction; it includes that first RSS read, pipeline construction, fit-argument preparation, fitting and prediction, but excludes metric calculation and the post-fit RSS read. RSS values are endpoint process snapshots and their difference, not peak memory.
