# V1 protocol status

The V1 analysis rules were fixed internally before the full run and are bound
to the configuration, registry, scope-lock, and environment hashes in the
frozen evidence. They were not deposited in a public registry or independently
timestamped before the study.

The historical `docs/protocol.md` uses the word “pre-registered.” That wording
refers to the internal protocol freeze and should not be read as a claim of
public preregistration. Its bytes remain unchanged because the full-run
manifest records its SHA-256 as provenance. This clarification does not alter
the frozen rules or the results. The manuscript uses “internally frozen” to
describe the protocol accurately.

The later V2 protocol is a separate study plan. It does not revise or replace
V1 results.
