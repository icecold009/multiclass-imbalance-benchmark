# V1 analysis implementation correction

The frozen protocol requires at least three complete dataset blocks for an
inferential raw-versus-condition comparison. The earlier analysis
implementation nevertheless passed one- and two-block comparisons to the
Wilcoxon routine and emitted p-values and Holm-adjusted values for them. This
was an implementation defect; it did not change the frozen protocol or raw
benchmark records.

The corrected analysis labels comparisons with one or two paired blocks as
descriptive, keeps their effect summaries, and leaves inferential and
Holm-adjusted p-values empty. Comparisons with no paired blocks are marked
skipped. For the frozen V1 data this yields 184 retained comparison rows: 104
eligible tests and 80 descriptive rows. Exactly one of the 104 eligible tests
remains significant after Holm correction. The 80 descriptive rows are not
included in any correction family.

The corrected output is generated by `scripts/run_analysis.py` from the
existing frozen valid-result and failure tables. It does not require or cause
a new benchmark model run.

Publication review on 2026-10-09 identified a separate mismatch with the
written complete-case rule. The frozen protocol specifies family-wide complete
dataset blocks for each metric and analysis family. The implementation uses
that rule for Friedman/Nemenyi analyses, but forms each raw-baseline row from
complete cells for raw and that alternative only. This pair-specific rule is
an implementation departure, not a protocol amendment. Consequently, all
raw-baseline effects, bootstrap intervals, and the 104 computed Wilcoxon/Holm
results are exploratory and do not count as planned confirmatory evidence;
the 80 rows with fewer than three pairs remain descriptive. The current
analysis script recomputes these values from the same frozen dataset-level
records. No model training was rerun.

## Post hoc interpretation and sensitivity

The planned significant numeric XGBoost block contains CNAE-9, Iris, and
Seeds, each with imbalance ratio 1.00. For all four scalar metrics, seven of
nine conditions (raw and six alternatives) exactly match raw on all three
dataset blocks. SMOTEENN and SMOTETomek occupy mean-rank positions 9 and 1.
ADASYN has complete cells on these balanced datasets and generated no new
training rows in 135 valid seed-fold records. On the other six numeric
datasets, ADASYN has 21 valid records spread across incomplete cells and 249
failures; those records do not form complete dataset-level outcomes. The
exact no-op pattern is specific to XGBoost; some balanced Random Forest
weighting and undersampling records differ from raw.

The original significance therefore describes a separation between two
cleaning methods on balanced controls, not evidence that minority-class
rebalancing improved performance. Balanced and near-balanced datasets remain
in scope because eligibility was set before the benchmark from public
multiclass status, feature/provenance checks, and minimum support, without
score-based filtering.

A separate post hoc macro-F1 analysis drops ADASYN and uses the remaining
eight numeric conditions on the nine datasets complete for every classifier.
Its deterministic 200,000-resample rank permutations gave $p=0.001845$ for
logistic regression, $p=0.047595$ for Random Forest, and $p=0.014400$ for
XGBoost; no exact raw-baseline follow-up survived Holm correction within its
seven-test classifier family. This changes both the condition set and
dataset coverage and does not isolate a causal explanation. The output files
are `adasyn_excluded_friedman.csv`, `adasyn_excluded_pairwise.csv`, and
`adasyn_excluded_imbalance_descriptive.csv`. The last file uses post hoc
strata IR = 1.00 (CNAE-9, Iris, Seeds; 3 datasets) and IR > 1.00 (the other
six numeric datasets); it contains descriptions only, with no stratum tests.

The mixed XGBoost balanced-accuracy/SMOTENC example also illustrates the
locked numerical rules: CMC's delta is +0.007018053 and Dermatology's is
$-2.22\times10^{-16}$. Under the $10^{-12}$ W/T/L tolerance this is one win
and one tie, but exact-zero Wilcoxon preprocessing would treat both as
nonzero. With only two pairs, the comparison remains descriptive and has no
Wilcoxon test.
